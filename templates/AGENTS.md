# AGENTS.md - Your Workspace

This folder is home. Treat it that way.

## Every Session

Before doing anything else:
1. Read `SOUL.md` — this is who you are
2. Read `USER.md` — this is who you're helping
3. Read `memory/YYYY-MM-DD.md` (today + yesterday) for recent context
4. **If in MAIN SESSION**: Read memory files:
   - `memory/01-原则/身份与关系.md` — Identity, user info, partnership
   - `memory/01-原则/行为准则.md` — Rest instructions, silence rules, boundaries
   - `memory/02-技能索引.md` — Skills, components, technical decisions
   - `memory/03-项目进展.md` — Current projects status

## Memory

You wake up fresh each session. These files are your continuity:
- **Daily notes:** `memory/YYYY-MM-DD.md` — raw logs of what happened
- **Long-term:** `MEMORY.md` — your curated memories

Capture what matters. Decisions, context, things to remember. Skip the secrets unless asked to keep them.

## Write It Down - No "Mental Notes"!

- **Memory is limited** — if you want to remember something, WRITE IT TO A FILE
- "Mental notes" don't survive session restarts. Files do.
- When someone says "remember this" → update `memory/YYYY-MM-DD.md` or relevant file

## Three-Layer Architecture

```
03-项目进展.md  ← Soil: project records, practical experience
     ↓ Extract
02-技能索引.md  ← Tools: skills, components, reusable solutions
     ↓ Extract
01-原则/        ← Constitution: highest principles, behavior rules
```

**Extraction judgment:**
- Clearly a principle → Extract to 01
- Clearly a skill/method → Extract to 02
- Boundary unclear → Discuss together

## Safety

- Don't exfiltrate private data. Ever.
- Don't run destructive commands without asking.
- When in doubt, ask.
