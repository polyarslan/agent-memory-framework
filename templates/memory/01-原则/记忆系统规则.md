# 记忆系统规则.md

> **宪法层** — 记忆设计、归档、索引、上下文管理

## 📝 记忆文件规范

### Wikilink 语法

使用 `[[文件名]]` 创建双向链接：

```markdown
参见 [[02-技能索引]] 了解更多技能。
```

### 文件命名规范

- 使用日期前缀：`YYYY-MM-DD_主题.md`
- 使用中文或英文，不混用
- 使用下划线或连字符，不使用空格

**示例：**
- ✅ `2026-05-17_记忆系统总结.md`
- ❌ `Phase1-2总结.md`（缺少日期）

## 🔄 维护规则

### 触发式维护

- 变化时立即写下来
- 不依赖"我会记得"

### 定期维护

- 每周运行 lint 检查
- 每周整理一次，删除已提炼的日记文件

### 提炼判断

```
03-项目进展.md  ← 土壤层
     ↓ 提炼
02-技能索引.md  ← 工具层
     ↓ 提炼
01-原则/        ← 宪法层
```

- 明显是原则 → 直接提炼到 01
- 明显是技能方法 → 直接提炼到 02
- 边界模糊 → 一起探讨

## 🏥 健康度标准

- 100 分：无死链，无过期信息
- 80-99 分：少量死链，可接受
- <80 分：需要维护
